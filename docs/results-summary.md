# 实验结果与证据边界

## 后训练

旧 5090 的五 checkpoint 对比为：SFT16000 55.2%、增强23000 58.4%、ActionEMA26000 55.6%、A路线29000 58.8%、B路线29000 62.8%。THU 的独立 B/C 对照为 B29000 159/250（63.6%），C student 与 C dynamic EMA teacher 均 151/250（60.4%）。这些结果支持“B29000 是当前测试候选中最好的 checkpoint”，但不同训练路线包含多项共同变化，不能把收益归因到单一技巧。

## 推理策略

在固定 B29000 下，固定50/30/20步分别为 63.6%、59.6%、66.8%；AutoHorizon 为 62.0%；Async25 为 65.2%；RTC25 为 60.0%。固定20步提高了成功率，但请求数约增加 2.36 倍，解释应是更高反馈频率带来的闭环折中。

## Agent

旧自定义 Agent 的纯 VLA、无记忆和冻结记忆分别为 63.6%、57.2% 和 60.4%。官方 RPent Agent 在 250 回合中为 162/250（64.8%，clean 107/125，randomized 55/125）。由于官方 Agent 与旧纯 VLA 的初态、环境版本和 seed 处理并非完全同源，这个差值只能作为工程结果，不能写成严格的因果增益。

## 复现边界

公开仓库不带权重、数据、仿真器、服务器环境和 API 凭据；完整数值需要在固定版本和相同任务协议下重新运行。所有失败回合应保留在结果账本中，不能只统计成功案例。
