# Evaluation Protocol

每组实验配置评测250回合：25个任务 × Clean/Randomized两种设置 × 每种设置5个预定义场景，Clean和Randomized各125回合。这里衡量固定任务集合下的场景鲁棒性，不将结果表述为未见任务泛化。

同批次固定任务、公共场景、checkpoint、归一化、BF16、10次去噪、batch1及50步预测窗；执行长度和调度方式由推理对照条件指定。使用RoboTwin原生eval_success，每个回合记录请求及实际seed、预算、结果、模型调用与异常类型。

初始化/专家规划故障、传输异常与正常策略失败分开记录；只有预定义客观环境故障可以按候选池顺延seed。正常失败进入成功率分母。续跑保留已验收结果及来源，不重复执行完成回合。

checkpoint筛选批次的B29000为157/250；后续独立Fixed50复核为159/250。C权重采用后续批次，同批次B29000为159/250。Agent沿用25任务及相同规模，但仿真版本、初态与原生seed顺延并非与纯VLA完全同源，因此不将162/250与159/250之差解释为严格因果增益。

推理前向时间是各策略实际请求的统计，输入轨迹并不恒定，不等于端到端任务时间或相同输入算子基准。没有通过本组实验主张统计显著性。
